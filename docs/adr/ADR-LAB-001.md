# ADR-LAB-001 — 产品与内部 Lab 独立交付

状态：实施合同已确认；实现尚待逐包验收。

来源：用户批准的《Oxrail：产品 Skill 与内部 Lab 分离开发交接书》v1.0（2026-09-08）。本记录固定决策，不重新比较架构方案。

- 产品包含 Skill 和提供真实能力所必需的运行组件、安全锁、租约、恢复和近期能力验证状态；发布安装根不包含实验、采集、报告或凭据 Demo。
- Lab 独立安装、依赖、启用、权限、配置、进程和存储，默认关闭。产品不主动发现或连接 Lab，不能通过环境变量启用隐藏实验入口。
- Lab 基础采集不依赖产品 Hook、Guard、profile、runtime-state 或产品数据目录。首个源适配器为 codex-local-hook-v1；真实验证前不宣称支持。
- 监控仅投影许可元数据，输出中性结果，不改变审批、输入、输出或执行 Agent 上下文。关闭或故障不解除产品租约。
- 原生对照需全新且完全不加载 Oxrail 的宿主环境；BYPASSED 不构成 Native baseline。实验计划及报告对执行 Agent 的隔离须实证。
- Chrome 是首轮真实路径；Native Computer Use 是唯一浏览器写执行者。真实输入、秘密、剪贴板、页面和登录截图不进入 Lab。
- 产品采用文件白名单和打包依赖图验证；实际安装器验证单列。仅产生本地发布 dry-run，不发布或推送。
- 顺序实施 WP-LAB-000 至 WP-LAB-007，各包独立提交，状态为 IN_REVIEW 或 BLOCKED。未知 Token、不可见动作及未跑的真实宿主测试不能算通过。
